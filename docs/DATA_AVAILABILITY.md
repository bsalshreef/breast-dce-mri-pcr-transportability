\# Data Availability



\## Source data



This study used publicly available, deidentified data from the BreastDCEDL resource and its source breast DCE-MRI cohorts: I-SPY1, I-SPY2, and the Duke Breast Cancer MRI dataset.



BreastDCEDL integrates imaging-derived resources and associated clinical metadata used in the present analysis.



No new patient-level source data were generated for this study.



\## Repository data policy



Patient-level source or derived data are not redistributed through this code repository.



The repository is intentionally designed to exclude clinical metadata, patient-level predictions, radiomic feature matrices, MRI images, segmentation masks, serialized fitted models, and patient identifiers.



Users seeking to reproduce the analyses should obtain the source datasets from their official repositories and comply with the applicable dataset access conditions, licenses, and terms of use.



\## Verified dataset identifiers



The following official dataset records provide access to the source resources:



\- BreastDCEDL, Zenodo version 4 (min-crop dataset): DOI 10.5281/zenodo.18114231

\- I-SPY1, The Cancer Imaging Archive: DOI 10.7937/K9/TCIA.2016.HdHpgJLK

\- I-SPY2, The Cancer Imaging Archive: DOI 10.7937/TCIA.D8Z0-9T85

\- Duke Breast Cancer MRI, The Cancer Imaging Archive: DOI 10.7937/TCIA.e3sv-re93



The BreastDCEDL data descriptor was published in Scientific Data (2026), DOI 10.1038/s41597-026-06589-6.



\## Local reproduction requirements


For local reproduction, the harmonized metadata file is expected to be named `BreastDCEDL_metadata_min_crop.csv`.


The analysis scripts use local input files obtained or derived from the official source datasets.



The harmonized metadata file is expected under the filename:



`BreastDCEDL\_metadata\_min\_crop.csv`



Users should verify the integrity of downloaded archives before extraction or analysis.



The repository does not redistribute source imaging data, patient-level metadata, radiomic feature matrices, or individual predictions.



The BreastDCEDL Zenodo record specifies the CC BY-NC 4.0 license. Users must review the applicable licensing and attribution requirements before reusing the data.
